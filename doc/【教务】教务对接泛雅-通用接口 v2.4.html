背景

​x
原教务系统对接泛雅方式为：开通FANYA中间库
单位本地部署的单位，泛雅没有本地部署的情况下，单位多数情况不愿意将数据库端口开放出去。
​
原方案为：
1.编写程序每天定时推送数据到泛雅数据库（数据时效性，同步数据量大）
2.本地部署数据中台，通过数据中台封装接口，或者同步数据到泛雅数据库（需要两台机器部署数据中台）
​
现通用方案：
在单位教务系统可以公网访问的情况下，提供泛雅对接的通用web接口，泛雅调用web接口获取数据即

ENC加密规则

xxxxxxxxxx
enc 加密方式：沿用泛雅中间库标准（泛雅平台与教务系统数据对接接口版22V1）
enc = md5( key + yyyy-MM-dd)   32位小写
例：
key = A37_57_384aff2ae056a
enc = md5(A37_57_384aff2ae056a2025-11-17)
enc = eb0db629cb5ccebc51a45d229263a740

教务方的流程：

  • 单位有对接泛雅需求后
  • 让泛雅项目提供对接使用的key（泛雅后台有配置）
  • 找立伦组人员本地部署webapi服务(公网是App服务)
  • 立伦组提供项目接口地址
